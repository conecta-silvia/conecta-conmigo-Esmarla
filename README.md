# Conecta conmigo · Esmarla

Tarjeta profesional digital de Maria del Mar Plano Mora (Esmarla), diseñada para consultar desde el móvil y compartir mediante un enlace, código QR o una placa NFC.

Reúne dos espacios profesionales con una presentación visual diferenciada:

## Oficia Mi Boda

Ceremonias civiles y simbólicas personalizadas.

Accesos a:
- Web oficial.
- Información sobre ceremonias bilingües en español e inglés.
- Formulario para dejar una reseña en Google.

## Bienestar Integral

Propuestas y herramientas para el cuidado personal y el bienestar.

Accesos a:
- Información sobre el escáner.
- Tienda de productos de Maria del Mar en VitalHealth.

Maria del Mar colabora de forma independiente con VitalHealth y recibe comisiones por las compras realizadas a través de su enlace.

## Funcionamiento

Miniweb estática alojada en GitHub Pages, adaptada a móviles y ordenadores.

El archivo `index.html` contiene el diseño, los textos y las imágenes. No requiere instalación ni incluye registro de usuarios, formularios, pagos o analítica propia.

Los servicios y las compras se gestionan en las páginas externas enlazadas, conforme a sus propias condiciones y políticas.

## Actualizaciones

Para modificar la miniweb, se actualiza el archivo `index.html` en la rama `main`. GitHub Pages publica los cambios después de completar el despliegue.
